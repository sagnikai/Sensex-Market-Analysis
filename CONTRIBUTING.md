# Contributing Guidelines

## Academic Integrity

This repository is part of an academic project. Contributions should maintain academic standards and proper attribution.

## Code Standards

1. **Java Code**: Follow standard Java naming conventions and include proper documentation
2. **Pig Scripts**: Include comments explaining data transformations
3. **Hive Queries**: Document schema definitions and query purposes
4. **Sqoop Commands**: Explain data ingestion workflows

## Submission Process

1. Fork the repository
2. Create a feature branch
3. Make your changes with clear commit messages
4. Submit a pull request with detailed description

## Documentation

All code contributions should include:
- Inline comments for complex logic
- README updates if adding new features
- Sample data or test cases where applicable
